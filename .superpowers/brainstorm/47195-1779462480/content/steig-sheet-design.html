Wie es funktioniert

1 — Datenquelle: Steig-Text
Jede Abfahrt bekommt ein quayText-Feld. Quellen in Priorität:
1. journeys.stops.quayText (API)
2. boardRef → "de:08222:2505:3:A"
(letztes Segment = Steig-Buchstabe)
3. nil → Badge wird ausgeblendet
2 — Karten-Pins: Koordinaten
Beim Sheet-Öffnen: einmalige Query aller Haltepunkte der Station mit ihren Koordinaten.
station(id: "2505") {
  stops {
    hafasID, name, lat, lon
  }
}
3 — Sheet-Inhalt
Das Sheet zeigt:
• Stationsname + Steig-Bezeichnung als Header
• MapKit-Karte mit allen Steig-Pins, gesuchter Steig orange
• Blauer Standort-Punkt (LocationManager, bereits im App)
• Abfahrten-Liste gefiltert auf diesen Steig
