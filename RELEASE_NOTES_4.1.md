# Version 4.1 - Release Notes

## Deutsch (App Store)

**Neu in Version 4.1:**

🎫 **Apple Wallet verbessert**
• D-Ticket kann jetzt zuverlässig zur Wallet hinzugefügt werden
• Fehler beim Erstellen des Wallet-Passes behoben

🔍 **Bessere Standortsuche**
• Verbesserte Fehlerbehandlung wenn keine Stationen gefunden werden
• Leerer Zustand führt jetzt direkt zum Stations-Picker

🐛 **Fehlerbehebungen**
• Apple Wallet Sheet zeigt jetzt korrekten Inhalt beim ersten Öffnen
• Diverse Stabilitätsverbesserungen

---

## English (App Store)

**What's new in Version 4.1:**

🎫 **Apple Wallet improved**
• D-Ticket can now be reliably added to Wallet
• Fixed error when creating Wallet pass

🔍 **Better location search**
• Improved error handling when no stations found
• Empty state now leads directly to station picker

🐛 **Bug fixes**
• Apple Wallet sheet now shows correct content on first open
• Various stability improvements

---

## Kurz (für Apple Review Notes)

This update fixes a critical bug with Apple Wallet pass generation (PKPassKitErrorDomain error 1) and improves the station search experience. No new permissions required.
